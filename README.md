# Sanatanam content mirror

Bhagavad Gita Sanskrit root text: 18 chapters, 700 verses. No modern commentary or translation included.

Text from Sanskrit Wikisource, licensed [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). Changes: whitespace/Unicode normalization and generated IAST transliteration. Source revision and retrieval date recorded in each pack.

Packs are gzip archives; `sha256` in manifest covers compressed bytes. Manifest version 1 contains Sanskrit only.
